# Interface and evidence guide

The React/TypeScript interface is a static application served by GitHub Pages. Recharts renders measured curves and training traces. Cytoscape renders bounded neighborhoods of reviewed dependency nominations. No database connection or server-side secret is needed to explore the notebook.

## Data contracts

`catalog.json` contains method-independent counts, curated compression runs, privacy summaries, finite-source points and historical test records. `literature.json` contains allowlisted bibliographic fields and current accepted ideas. `latest-jobs.json` indexes immutable `jobs/<run-id>.json` outcomes. Types are in `web/src/types.ts`.

Compression retention is measured using reference tokens or receiver request tokens, including the receiver chat wrapper where labeled. Synthetic controls use UTF-8 bytes. Finite-source length is an expected symbolic cost, and leakage is mutual information in bits. These units are not interchangeable. Missing observations are labeled “Not measured”; infeasible calculations are excluded from plotted measurements and preserved in exports.

Each figure provides a data table and CSV. SVG exports include a title, evidence label and series legend. The Literature graph also provides a text relationship list. Hash routes support direct links and reloads on Pages. Navigation collapses on small screens; charts remain within the viewport and data tables scroll inside their containers.

## Verification

The frontend unit tests cover owner verification, fixed workflow dispatch, cancellation boundaries, error handling, session-memory credentials, missing values, access-condition separation and CSV encoding. Python tests cover export checksums, foreign-key consistency, private-value rejection, invalid job inputs, outcome idempotence, failure preservation and JUnit counts. Browser integration tests cover all routes on desktop/mobile, filtering, exports, search, and disabled anonymous execution.

The independent research suites test the underlying methods. CPU fixtures are deliberately small. Passing them does not establish real-model quality, GPU latency or privacy certification. Current workflow artifacts and the published per-suite record are the reproducible source for new test outcomes.
